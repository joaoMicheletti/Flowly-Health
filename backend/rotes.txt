==========================================================
FLOWLY HEALTH
ROTAS PARA POPULAR O BANCO DE DADOS
==========================================================

Base URL

http://localhost:3000

----------------------------------------------------------
1 - LOGIN
----------------------------------------------------------

POST /auth/login

Body:

{
  "email": "admin@flowly.com",
  "password": "123456"
}

Resposta:

{
  "access_token": "JWT_TOKEN"
}

Utilize este token em todas as demais requisições.

Authorization:

Bearer SEU_TOKEN

==========================================================
2 - CADASTRAR USUÁRIO
==========================================================

POST /users

Authorization:
Bearer TOKEN

Body:

{
  "name": "Administrador",
  "email": "admin@flowly.com",
  "password": "123456",
  "role": "ADMIN"
}

Roles disponíveis:

ADMIN
DOCTOR
RECEPTIONIST

Exemplo Médico

{
  "name": "Dr João Dias",
  "email": "joao@flowly.com",
  "password": "123456",
  "role": "DOCTOR"
}

Exemplo Recepcionista

{
  "name": "Maria Souza",
  "email": "maria@flowly.com",
  "password": "123456",
  "role": "RECEPTIONIST"
}

==========================================================
8 - AGENDAR CONSULTA
==========================================================

POST /appointments

Authorization:
Bearer TOKEN

Body:

{
  "patientId": "UUID_DO_PACIENTE",
  "userId": "UUID_DO_MEDICO",
  "date": "2026-07-25T14:00:00.000Z",
  "type": "CONSULTATION"
}

Tipos disponíveis

CONSULTATION
RETURN
EVALUATION

==========================================================
9 - LISTAR CONSULTAS
==========================================================

GET /appointments

Authorization:
Bearer TOKEN

==========================================================
10 - ALTERAR STATUS DA CONSULTA
==========================================================

PATCH /appointments/{appointmentId}/status

Body:

{
  "status": "FINISHED"
}

Status disponíveis

SCHEDULED
FINISHED
CANCELLED
